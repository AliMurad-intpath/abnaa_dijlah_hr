Fonts used by the PDF engine
- TimesNewRoman.ttf / TimesNewRoman-Bold.ttf : the document font (Latin + Arabic). When both are present the engine uses
  them for every printed value, and the blank form PDFs were built with them.
- LiberationSerif-*, FreeSerifArabic-* : fallback look-alikes, used only if the two files above are removed.
- DejaVuSans-* : symbols (tick marks) and last-resort fallback.
Times New Roman is a Microsoft/Monotype font: keep the repository private.
